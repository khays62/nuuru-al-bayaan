# Hagaha Isticmaalaha (User Guide)

## Navigation
- Dashboard → Kooban
- Students → Liiska ardayda + filters + CRUD
- Grades → Maareynta Grade Sections
- Subjects → Maareynta Maaddooyinka

## Students List
- Search: magac ama Student ID
- Filters (cascading): Academic Year → Grade → Shift → Section
  - Section waa la adeegsan karaa kaliya marka saddexda hore la doorto
  - Haddii aan helin wax Section ah, waxaa muuqda toast
- Sort: Created/Name/Student ID (↑/↓)
- CSV: Soo dejinta bogga hadda

## Reassign Enrollment
- Tag Students → ku dhufo "Reassign" ee safka ardayga
- Dooro Year, Grade, Shift → kadib Section saxda ah
- Xaqiiji → nidaamku wuxuu u wareejiyaa enrollment-ka qaybta cusub (isla Academic Year)

## Student Profile
- Macluumaad guud + Latest enrollment
- History: liiska sannadihii hore (Reassign per-row ka saarnay; isticmaal Students page)

## Grades
- Filter: Grade, Academic Year, Shift; Section input
- CRUD: Abuurid/Update/Tirtirid Grade Section

## Subjects
- Filter by Grade
- CRUD Subject + xiriirka grades
